# IOP — demo web

Questa cartella contiene una demo statica dell'Indice di Orientamento Politico.

## Prova in locale
Apri `index.html` con un browser.

## Pubblicazione gratuita con GitHub Pages
1. Crea un nuovo repository su GitHub, per esempio `iop-demo`.
2. Imposta il repository come **Public**.
3. Carica `index.html` nella cartella principale del repository (Add file → Upload files → Commit changes).
4. Apri Settings → Pages.
5. In Build and deployment scegli **Deploy from a branch**.
6. Seleziona branch `main` e cartella `/ (root)`, poi Save.
7. Attendi la pubblicazione: GitHub mostrerà l'indirizzo del sito nella sezione Pages.

Questa è una demo con quattro domande dell'asse Economia. I punteggi e le associazioni ideologiche sono dimostrativi e non costituiscono ancora il test completo.
